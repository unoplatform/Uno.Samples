# MSAL sample

This app is an example of signing users in with MSAL.NET from a single Uno Platform project
targeting Android, iOS, WebAssembly and Desktop, using the `Uno.WinUI.MSAL` add-in only.

**Start here: [../MSAL-SETUP.md](../MSAL-SETUP.md)** — app registration, the redirect URI each
platform needs, how to run each head, and troubleshooting.

To point it at your own app registration, put your Application (client) ID in
[Authentication/MsalConfig.cs](Authentication/MsalConfig.cs). The *Platform setup* page inside the
running app shows the same setup reference on-device.
